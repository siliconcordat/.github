# Siliconcordat Organization Hub

This repository holds the public organization profile, unified master plan, collaboration guide, and live build tracker for Siliconcordat.

## Key Documents

- [Organization Profile](profile/README.md): plain-language overview of the five-layer stack, trust firewall, and active repositories.
- [Master Plan](MASTER-PLAN.md): full architecture, three-machine topology, composable domain packs, verification gates, and rollout milestones.
- [Contributing Guide](CONTRIBUTING.md): cross-team collaboration rules, prose and privacy checks, review lanes, and verification gates.
- [Live Status](STATUS.md): current commits, planning issues, and independent verification state across all repositories.
- [Wave 1 to 4 Update](UPDATES/2026-11-19-wave1-4-update.md): verified stack summary, empirical proofs and dead ends, external readiness tiers, and concrete next steps.
- [Outreach Playbook](OUTREACH-PLAYBOOK.md): verified Tier A, Tier B, and Tier C publish/outreach sequence, credibility guardrails, owner decision checklist, and layer execution issue router.
- [Formal Verification MDE POC](https://github.com/siliconcordat/mde/issues/4): canonical end-to-end initiation blueprint for the first Model-Domain-Engine proof of concept.
- [Adaptive Warp ML Workbench OS POC](https://github.com/siliconcordat/warp/issues/4): canonical end-to-end blueprint for the adaptive Linux ML workbench OS on UX582HS (RTX 3080).
